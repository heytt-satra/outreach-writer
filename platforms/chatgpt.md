# Using Outreach Writer on ChatGPT

## Option 1: Paste into any chat

Copy the contents of `prompt.md` and paste it at the start of your message like this:

```
[paste prompt.md contents here]

Now help me write a cold email to...
```

## Option 2: Create a Custom GPT

1. Go to chat.openai.com and click "Explore GPTs" then "Create"
2. Switch to the "Configure" tab
3. Give it a name: "Outreach Writer"
4. In the Instructions field, paste the full contents of `prompt.md`
5. Save and start using it

The Custom GPT will remember the instructions every time you use it. No need to paste the prompt again.

## Tips

- Tell it who you are (what you have built, your skills, what you want)
- Tell it who you are writing to and one specific thing you noticed about them
- Say which format you need: cold email, LinkedIn DM, or connection note
